# 땅따먹기 실제 지도 데이터

게임은 인터넷이나 GIS 라이브러리 없이 전처리된 텍스트 지도를 읽는다.
`world.txt`는 세계 100×70, `korea.txt`는 한반도 160×220이며,
`countries.json`과 `country_maps`는 국가별 지도와 목록이다. 국가 지도는
가장 큰 육지 영역의 경계 사각형을 기준으로 주변 여백을 추가한다. 범위 안의
주변 국가와 섬도 포함하지만 멀리 떨어진 섬과 해외 영토는 빠질 수 있다.
실제 국경선이나 도시 위치는 게임에 표시하지 않는다.

각 문자는 게임 지형을 나타낸다.

| 구분 | 문자와 지형 |
|---|---|
| 물 | `w` 심해, `c` 연안, `r` 강, `l` 호수 |
| 초원 | `p` 평야, `g` 초원, `t` 습지 |
| 사막 | `d` 사막, `n` 설원, `j` 정글 |
| 숲 | `h` 언덕, `b` 수풀, `f` 숲 |
| 산 | `k` 암석, `m` 산, `v` 절벽 |

선택한 게임 크기에 맞춰 가장 가까운 저장 셀을 사용하므로 강과 작은 섬 등은
생략될 수 있다. 국가 지도는 위도에 따른 경도 길이와 육각형 비율을 고려해
세로 크기를 정하고, 300칸을 넘으면 전체 크기를 축소한다.

## 지형 분류와 한계

Natural Earth 1:10m 육지·호수와 200m 수심선을 사용한다. 호수는 육지·바다보다
우선하며, 바다는 200m 수심선 안쪽을 심해, 그 밖을 연안으로 근사한다. 강
중심선은 실제 지도 생성에 사용하지 않아 육지가 강 타일로 덮이지 않는다.

Copernicus 2019 토지 피복의 경작지·습지·관목·숲·나지·눈을 사용한다.
열대 위도 23.5도 이내의 숲은 정글, 나지는 사막으로 근사하므로 실제 기후나
사막 여부를 확정하지 않는다. 고도 250~700m의 평야·초원·수풀은 언덕,
700m 이상은 산 또는 나지의 암석으로 분류한다. 고도 700m 이상에서 인접
샘플의 고도 차가 400m 이상인 곳은 절벽으로 근사하며, 해상도와 샘플링에
따라 실제 경사와 다를 수 있다. 눈은 고도 판정보다 우선한다.

토지 피복과 고도는 0.1도 간격의 기반 자료를 최근접 샘플링한다. 육지의
피복 자료가 없는 극지 등은 별도의 피복 판정 없이 초원이나 고도 지형으로
처리한다. 원본 해상도, 투영 및 게임 격자 때문에 실제 지형과 차이가 생긴다.

심해·연안·산·절벽은 기본적으로 이동할 수 없지만 구매할 수 있다. 이동 불가
타일은 도시와 연결된 이동 가능 타일에 인접하면 활성화되나, 그 너머로 연결을
전달하지 않는다. 연안·강·호수에 항구를 지으면 해당 타일을 통행할 수 있고
주기마다 식량 2를 생산한다. 항구 건설 비용은 목재 5, 석재 3이다. 도시의
기본 생산은 식량·목재·석재 각각 1이며, 철과 사치품은 0으로 시작한다.

활성 항구를 선택해 연결 항구를 건설하면 소유자가 없는 연안을 구매하고 항구를
지을 수 있다. 심해·연안의 최단 바닷길을 이용하며 상대가 소유한 수역은 통과할
수 없다. 좌우 연결 지도는 바닷길에도 적용된다. 연안 구매비는 기존 도시 거리
규칙을 따르며, 항구 건설비는 바닷길 한 칸마다 설정된 거리당 증가율을 적용한다.
목적지는 화면에서 탐색하고, 건설 요청 시 서버가 현재 경로와 비용을 다시 확인한다.

연결된 두 항구를 원래 소유자가 모두 보유하면 그 사이의 영토 연결이 유지된다.
한쪽의 소유자가 바뀌면 일시 중단되고 원래 소유자가 항구를 보존해 다시 차지하면
복구된다. 어느 한쪽 항구가 철거되면 연결이 영구 삭제된다. 건설된 연결은 나중에
바닷길 중간 타일의 소유자가 바뀌어도 유지된다.

## 지도 재생성

`10m_physical`, `ne_10m_admin_0_countries` 원본 폴더와
`global_landcover.tif`, `global_elevation.tif`가 필요하다. 저장소 루트에서
전처리 도구 의존성을 설치하고 실행한다.

```powershell
python -m pip install -r landgrab\tools\requirements.txt
python landgrab\tools\build_landgrab_countries.py
```

위 명령은 세계·한반도·국가 지도를 모두 재생성한다. 기존
`build_landgrab_maps.py`는 구 다섯 지형 지도용 도구이며, 새 지형 분류에는
위 명령을 사용한다. 게임 실행과 패키징에는 전처리 도구가 필요하지 않다.

## 자료 출처

- [Natural Earth 1:10m](https://www.naturalearthdata.com/): 국가 영역, 육지,
  호수, 강 및 SRTM Plus 기반 수심선.
- [Copernicus Global Land Cover 100 m, 2019, Collection 3](https://doi.org/10.5281/zenodo.3939050),
  Buchhorn 등 (2020), CC BY 4.0: 토지 피복.
- [NOAA ETOPO 2022](https://www.ncei.noaa.gov/products/etopo-global-relief-model):
  지표 고도.

`global_landcover.tif`와 `global_elevation.tif`는 위경도 -180~180, -90~90의
0.1도 간격(3600×1800) GeoTIFF다. 고도 기반 자료에서는 바다 수심을 제거했으며
수심 구분에는 Natural Earth 수심선을 별도로 사용한다.
