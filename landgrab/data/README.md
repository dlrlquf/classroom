# 땅따먹기 실제 지도 데이터

두 텍스트 파일은 실행 중 다운로드 없이 사용하는 전처리 지도다. 각 문자는 물(`w`),
초원(`g`), 사막(`d`), 숲(`f`), 산(`m`)을 나타낸다. 게임의 가로·세로 칸 수에 맞춰
각 칸의 중심에 가장 가까운 저장 데이터를 선택하므로 작은 섬과 지형은 생략될 수 있다.

- `world.txt`: 경도 -180~180, 위도 -90~90; 100×70.
- `korea.txt`: 경도 124~132, 위도 32.5~43.5; 160×220. 한반도와 주변 육지·바다가 포함된다.

## 전 세계 기반 데이터

- `global_landcover.tif`: 2019년 토지 피복 분류 코드, 칸당 1바이트.
- `global_elevation.tif`: 2022년 지표 고도(미터), 칸당 부호 있는 2바이트.

두 파일은 EPSG:4326 좌표계의 경도 -180~180, 위도 -90~90 범위를 0.1도 간격
(3600×1800)으로 저장한 압축 GeoTIFF다. 지형 원본의 대표 지점을 최근접 샘플링하므로
칸 내 지형의 면적 비율을 나타내지는 않는다. 토지 피복 원본의 범위는 위도 -60~80도이며,
나머지 극지방에는 자료 없음(255)을 저장한다. 원본의 자료 없음(0)도 유지한다.
물로 분류된 칸과 토지 피복 자료가 없고 고도가 0m 이하인 칸의 고도는 0으로 저장해
바다 수심을 제외한다. 지표 고도는 가장 가까운 정수 미터로 반올림한다.

이 기반 데이터로 세계지도를 재생성하거나 향후 대륙·국가 범위의 지도를 만들 수 있다.
게임에서는 위의 텍스트 파일을 그대로 사용한다.

## 자료와 변환

- [Copernicus Global Land Cover 100 m, 2019, Collection 3](https://doi.org/10.5281/zenodo.3939050),
  Buchhorn, Smets, Bertels, De Roo, Lesiv, Tsendbazar, Herold & Fritz (2020),
  CC BY 4.0. [COG 제공처](https://source.coop/cboettig/land-cover).
- [NOAA ETOPO 2022, 60초 지표 고도](https://www.ncei.noaa.gov/products/etopo-global-relief-model).

토지 피복의 바다와 내륙 수역은 모두 물로 처리하며 수심은 사용하지 않는다. 피복 자료가
없는 극지 등은 지표 고도가 0m 이하면 물, 그 외는 육지로 구분한다.

세계지도의 각 칸은 해당 구간의 0.1도 기반 데이터에서 물로 분류된 표본이 90% 이상이면
물이다. 그렇지 않으면 육지 표본만의 평균 고도가 1,000m 이상일 때 산으로 판정한다.
나머지 육지는 구간에서 가장 많은 초원·숲·사막 분류를 사용하고, 동률이면 초원, 숲,
사막 순서로 선택한다. 피복 자료가 없는 육지는 초원으로 분류한다. 이는 위경도 격자의
표본 비율이며 면적 가중치는 적용하지 않는다. 기본 크기 100×70 외의 게임 지도는 이
결과를 최근접 샘플링하므로 같은 비율 기준을 각 게임 칸에 다시 적용하지는 않는다.

한반도 지도는 기존처럼 표본 지점의 고도 700m 이상을 산으로 처리한다. 두 지도 모두
나무 피복은 숲, 나지는 사막, 관목·초지·농지·도시·습지·눈 등 나머지 육지는 초원으로
단순화한다. 따라서 나지가 실제 사막이 아닐 수도 있고 고원이나 눈 덮인 평야도 게임
지형과 정확히 일치하지 않는다. 축소와 육각형 표현으로 실제 해안선과 차이가 생길 수 있다.

저장된 기반 데이터로 세계지도만 다시 만들려면 `rasterio`를 설치하고 저장소 루트에서
`python landgrab\tools\build_landgrab_maps.py --world-from-base`를 실행한다. 인터넷은 필요하지 않다.
기존 원본 자료로 세계·한반도 지도를 모두 재생성하려면 `numpy`와 ETOPO 2022 60초 지표
GeoTIFF도 필요하며, `python landgrab\tools\build_landgrab_maps.py <ETOPO GeoTIFF 경로>`를 실행한다.
이 경우 Copernicus 원본을 인터넷으로 읽고, 세계지도도 400×280 최근접 샘플과 700m
산 기준으로 덮어쓴다. 위의 구간 집계 세계지도를 사용하려면 이후
`python landgrab\tools\build_landgrab_maps.py --world-from-base`를 다시 실행한다.

전 세계 기반 데이터를 다시 만들려면
`python landgrab\tools\build_landgrab_base.py <ETOPO GeoTIFF 경로>`를 실행한다. 원본 토지 피복
GeoTIFF를 로컬에 보관한 경우 `--land-cover <GeoTIFF 경로>`를 추가하면 오프라인으로
전처리할 수 있다. 두 스크립트 모두 전처리 도구만 필요하며 게임 실행에는 필요하지 않다.
